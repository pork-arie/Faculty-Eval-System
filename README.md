A web-based **Faculty Evaluation System** for **Northwest Samar State University (NWSSU)**.  
It provides separate modules for **Administrators** and **Users**, allowing students to evaluate faculty members and admins to manage evaluations, users, and reports.

---

## 📖 Overview

The Faculty Evaluation System is designed to simplify the process of evaluating faculty performance.  
It includes an admin dashboard for managing evaluation forms, faculty records, and reports, while users can log in, submit evaluations, and view their evaluation history.

---

## ✨ Features

### 👤 User Module
- User registration and login
- Evaluate faculty members
- Submit evaluation forms
- View evaluation history
- Update profile information

### 🛠️ Admin Module
- Admin dashboard
- Manage faculty records
- Manage users and accounts
- Create and manage evaluation periods
- View evaluation results
- Generate reports and analytics
- Export evaluation data
